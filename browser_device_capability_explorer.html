Browser & Device Capability Explorer

Educational laboratory for exploring what a normal webpage can discover about the browser, device, display, hardware and web platform.
Security boundary: This application only uses browser APIs available to the webpage. It does not silently access passwords, browser history, other tabs, arbitrary private files, SMS, contacts, IMEI or other protected operating-system data. Permission-gated APIs are tested only where explicitly requested by a user action.

Display Reliability GuideInterpretation
High reliability
Screen size, viewport, orientation, color depth, touch capability and browser-reported DPR.
These values are reliable as browser-reported values. They should not automatically be interpreted as raw physical hardware specifications.
Capability-level reliability
HDR, P3/wide-gamut and related media-query results.
These indicate what the user agent/output environment reports as supported. They do not prove that a capability is currently active.
Experimental
Refresh-rate estimation using requestAnimationFrame.
The result represents observed browser rendering callback timing. It is not a direct hardware refresh-rate sensor.
Not exposed directly
Exact physical screen inches, exact physical DPI, panel manufacturer, panel technology and guaranteed native physical resolution.
Do not derive these from CSS pixels and DPR as if they were guaranteed hardware specifications.
